# 출시 완성도 개선 (2026-09-17)

## 실제 장면 연결

- 메인 메뉴의 `게임 시작`을 `MansionExploration` 장면에 연결했다.
- 응접실→서재→지하실의 3단계 탐색 흐름과 단서별 관계 변화를 구현했다.
- 조사 결과 패널과 위험·보상·선택 근거가 포함된 다음 행동 CTA를 추가했다.
- 잠긴 방, 조사 완료, 반복 조사 방지, 이전 방 재방문 상태를 구분했다.
- `GameState`에 탐색 상태와 단서 획득 신호를 추가하고 중복 획득 테스트를 보강했다.
