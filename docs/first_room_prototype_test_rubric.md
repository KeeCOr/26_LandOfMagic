# LivingMansion 10인 첫 방 프로토타입 테스트 루브릭

## 목적
LivingMansion의 남은 핵심 리스크는 “첫 방을 조사한 뒤 단서 변화와 다음 방 선택 이유가 플레이어에게 바로 읽히는가”이다. 이 루브릭은 기능 목록이 아니라 첫 3분의 이해도를 검증한다.

## 대상 페르소나
- 방치형 자동 전투, 저택 탐색, 짧은 성장 루프를 좋아하는 PC 플레이어
- 직접 조작보다 배치/선택의 결과를 읽는 플레이를 선호하는 사람

## 진행 순서
1. 플레이어에게 게임 설명을 15초 이하로만 제공한다.
2. 첫 방에 진입해 조사 가능한 오브젝트를 직접 선택하게 한다.
3. 첫 단서 획득 후 멈추고 “무엇이 바뀌었나요?”라고 묻는다.
4. 다음 방 후보를 보여주고 “어느 방을 고르겠나요? 왜인가요?”라고 묻는다.
5. 첫 3분 종료 후 반복 의향을 1~5점으로 기록한다.

## 통과 기준
- 단서 변화 설명 성공: 10명 중 7명 이상
- 다음 방 선택 근거가 단서/위험/보상 중 하나와 연결됨: 10명 중 6명 이상
- 같은 막힘 지점: 3명 미만
- 반복 의향 평균: 3.5점 이상

## 실패 시 개선 우선순위
1. 단서 변화 설명 실패가 많으면 단서 획득 피드백 문구와 시각 강조를 먼저 고친다.
2. 다음 방 선택 근거가 약하면 방 카드에 위험, 보상, 단서 연결 문장을 추가한다.
3. 조작 막힘이 많으면 첫 방 상호작용 수를 줄이고 CTA를 하나로 고정한다.
